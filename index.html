Langkah Setup Google Sheets (2 Menit):

  1. Buka Google Spreadsheet baru di Google Drive Anda.
  2. Klik menu Extensions → Apps Script.
  3. Hapus kode bawaan, lalu tempel kode Code.gs di samping.
  4. Klik Deploy → New deployment → Web app.
  5. Set Execute as: Me dan Who has access: Anyone, lalu salin URL Web App ke form di atas.
